# Public Transport Management System

## Project Description

The **Public Transport Management System** is a Python-based application designed to simulate the daily operations of a public transportation service. The project demonstrates object-oriented programming (OOP) principles by managing vehicles, drivers, routes, passengers, and trip scheduling within a single system.

The application allows users to assign drivers to vehicles and routes, manage passenger bookings, calculate travel distances, and monitor transport operations. It also includes input validation and exception handling to ensure reliable and accurate data processing.

## Features

* Register and manage transport vehicles
* Assign drivers to specific routes
* Create and manage transport routes
* Book passengers onto available trips
* Track travel distance (kilometers)
* Calculate trip information
* Validate user input and handle errors gracefully
* Generate simple transport reports

## Technologies Used

* Python 3

## Concepts Demonstrated

* Object-Oriented Programming (Classes and Objects)
* Inheritance
* Custom Exceptions
* Functions and Methods
* Lists and Dictionaries
* Loops and Conditional Statements
* Input Validation
* Error Handling (`try`/`except`)
* Date and Time Handling (`datetime` module)

## Sample Workflow

1. Register a vehicle.
2. Assign a driver to the vehicle.
3. Create a transport route.
4. Book passengers for a trip.
5. Record the trip distance.
6. Display trip details and transport reports.

## Learning Objectives

This project was developed to strengthen practical Python programming skills by applying object-oriented design to a real-world transportation scenario. It demonstrates how software can be used to organize transport operations, improve scheduling, and manage transportation resources efficiently.
